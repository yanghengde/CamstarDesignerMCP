# CLF 第三批实施：声明参数与交付证据

日期：2026-10-25。接续 [第二批](clf_core_phase2_2026-10-25.md)。本批对应 F41 声明生命周期的受限实现与 F45 交付证据清单；实际数据库发布、WCF 部署与真实运行值联动仍未完成。

## 使用方式

在工程排查的“查看逻辑 → 声明与引用”中查看声明参数，直接“新增声明参数”“编辑”或“准备删除”。方向、参数数量和值类型以中文说明配合官方名称展示；数据类型、数量、值类型、特殊处理选项从本机 SDK 的真实目录读取。

系统规则的编辑表单默认并强制先准备独立客户副本。未附着、未被直接调用且官方未标记使用的客户规则，可准备参数新增、改名、类型、方向、多重性、具体对象及说明/备注变更和删除。原规则已有入口/调用者时只允许说明/备注变更；结构变更需明确迁移或先准备副本，当前不会自动重绑或覆盖既有附着值。

表单提交只加入方案。方案按字段展示原声明与拟定值，仍需官方预检、审核差异、明确保存及回读。删除/改名遇到本规则表达式中的 `CLF::参数` 或 `DBCLF::参数` 引用时阻止，并要求先明确修改引用。

“修改方案 → 查看验收与交付清单”读取已有阶段回执，展示预检、工作文件保存、编译、同源测试、数据库发布、WCF 和部署来源的证据。报告可导出 JSON，不执行测试或发布。

## 官方合同与实现

已读取本机 Siemens 2026 帮助 `Designer2/Help/Content/Designer/06DesignCLFs/Adding_CLF_Parameters.htm` 和 `CLFs_Window.htm`。帮助明确声明的生命周期和附着实例更新要求，不能把库声明编辑当作所有入口已迁移。

已通过安装的 `Camstar.Metadata.dll`（程序集版本 10.6.0.0）核实：

- 声明由 `FunctionParameter` 表示，CLF 默认函数拥有其真实参数身份。
- 使用官方 `FunctionDefinition.NewParameter` 工厂，设置官方目录对应的类型、参数多重性、值类型、特殊处理 ID 与名称；Object 的具体 CDO 同时核对名称和真实 ID。
- 通过 `CLFDefinition` / 默认函数的集合及状态机制保存；不是直接写 Access 表。仅构造普通对象或改名称字符串不足以证明参数已保存。
- 官方 SaveAll 后重新加载，按稳定参数 ID 和工作区校验全部声明字段、父函数、顺序及关键目录 ID；删除另外确认稳定身份已消失。
- `CopyAsNew` 可能只保留具体 CDO/特殊处理的 ID，而内存显示名暂时为空。声明预检与原值比较按官方目录 ID 解析名称，保留原始引用显示值作诊断；不靠猜测补名，无法解析的身份不能通过修改校验。

新增严格操作：`add_clf_declaration`、`update_clf_declaration`、`remove_clf_declaration`。属性包沿用官方 `Name / Direction / DataType / ParamMultiplicity / TypeMultiplicity / FunctionParmUsage / CDOType / Description / Notes / DefaultValue`；更新和删除必须带完整原值，额外字段、伪造 ID、无效方向/多重性不能穿过合同。

不能通过通用 `patch/delete kind=clf_parameter` 绕过专用流程；同一个声明以 `function_parameter` 别名访问时，原生桥也识别其所属 CLF 并阻止绕过。创建/更新/删除计数使用统一操作分类，原 Designer 安全策略继续适用。CLF 助手仍只能预检，不具备新增写入工具。

新增 `designer/clf_parameters.py`、`designer/clf_report.py` 及相关测试。详细声明编辑目录仅在工作区明确请求附着参数时展开，普通 CLF 读取继续保持轻量。

## 验证与缺口

- 正式测试目录回归：669 项通过、60 项按环境条件跳过；新增声明合同与报告覆盖严格字段、通用操作绕过、版本/产物漂移、归属、筛选范围和阶段真实性。
- 安装 SDK 的隔离复制验收：完整新增、保存回读、改名、类型/方向/多重性、具体 CDO、说明/备注与删除通过；旧原值拒绝，仍被表达式引用时拒绝删除；已有绑定阻止结构变更而允许说明维护；函数参数别名不能绕过。
- 复制带有声明的客户规则后可继续修改副本声明；参数稳定身份与原规则分离，原值和类型核验保留。普通参数及 Object 具体类型、多重性组合分别验证，不依赖空声明模板推断复制行为。
- 原工作 MDB 只作为复制源，写入均在隔离文件进行，校验原文件 SHA-256 保持一致。浏览器验收记录位于 `tmp/clf-parameters-phase3`。
- 浏览器通过真实目录准备 Object / Product / In/Out / 0..* / ListOrScalar 声明，官方方案预检、保存回读和 MetadataCompile 完成；再次打开规则能读出并编辑保存后的参数。交付清单核验保存/编译，保留同源回归、发布及部署缺项。
- 页面无脚本错误或重复元素身份。352 像素视口可用宽度 337，文档宽度同为 337；参数弹窗内容宽度与可用宽度均为 290，无横向溢出。正式 8032 服务加载新功能；没有向实际业务环境提交交易或发布。
