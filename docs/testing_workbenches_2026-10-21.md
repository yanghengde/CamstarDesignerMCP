# WCF / CLF 功能测试工作台

## 入口与操作

- `/wcf-test`：选择环境、工作 MDB 与 WCF 产物，检索客户端真实服务，选择实际方法，填写字段表单或 JSON，配置返回字段及断言后执行。
- `/clf-test`：读取真实 CLF 的调用 ID、顺序、参数与官方引用入口，通过选定业务服务提交测试输入，分别展示交易结果和目标 CLF 的运行证据。
- 设计进度 WCF 步骤、CLF 助手选中定义处提供带上下文的入口。工作台的所有主导航增加两张测试页。

环境地址填写 WCF 基础目录，不能是单个 `.svc`、含凭据的 URI 或带 token 的查询地址。业务账号与 SQL / Windows 共享账号分开。页面保存密码时使用 Windows DPAPI，并通过后台标准输入交给独立进程，不写入命令行或明文请求文件。

## 执行链路

1. 请求经过本机同源限制及当前配置用户检查。
2. 执行前核对工作 MDB 哈希、客户端哈希、环境版本；按原生成回执逐个验证客户端文件，不允许额外 DLL 或路径越界。
3. 使用生成的客户端程序集读取公开签名，选择 `(ServiceData, ServiceRequest, out ServiceResult)` 方法；官方类型构造器校验字段、引用、数组、枚举及基本类型，不在浏览器伪造 SOAP 格式。
4. 通过隔离的 .NET Framework 进程执行真实方法；终结点由官方客户端配置克隆，并绑定到所选环境基础目录。单次调用最多为环境超时与 `DESIGNER_TEST_TIMEOUT` 的较小值。
5. 可在写入成功后执行独立 `Load` 回读，字段断言使用回读值。回读失败时保留先前写入回执，不将整次操作误写为“未保存”。
6. 回执写入专用 SQLite；同一用户和请求标识只接受相同请求且只执行一次。刷新后恢复运行状态，正常退出等待任务；异常退出遗留任务标记业务结果未知，不自动重放。

后端核心位于 `designer/testing.py`、`testing_runtime.py`、`testing_store.py` 和 `TestWcfClient.cs`；页面及 API 位于 `static/testing.*` 和 `web/testing_routes.py`。现有 MCP 工具和 CLF 助手只读限制保持原有边界，测试只由页面显式请求触发。

## 断言及边界

- 预期结果为业务成功或业务拒绝，可再匹配业务提示，以及 `exists`、`equals`、`contains` 字段断言。布尔值不当作整数比较。
- 未提交、null、空字符串、零、false 与空列表在请求模型和用例中分别保留。null 最终按官方客户端序列化，不能未经验证就认定为清空字段。
- 所有未确认读取语义的方法均按可能写入处理。需要页面本次写入开关和既有测试目标配置；保存用例时移除写入授权。
- 不支持跨独立进程维持多次 `AddDataTransaction` / `CommitTransaction` 的有状态事务，不自动猜测服务操作顺序。
- CLF 定义顺序单独展示。只有实际 `DebugResponse.Trace` 中明确的 CLF 名称或命名属性才作为触发证据，不能以业务提示或文本中提及名称代替。轨迹不可用时继续保留交易结果，目标 CLF 状态为未验证。
- 返回条数或深度超出显示上限时标记截断，不给出完整回执断言通过。敏感字段、具名密码参数和会话凭据脱敏。
- 执行结果仅代表记录中的请求和版本，不据此推断当前部署 DLL 版本与设计包一致，也不自动完成设计进度的整体运行验收。

## 验证

- 公共 API 覆盖环境更新、密码保留、用户归属、真实运行到落盘、重复请求去重、源漂移、测试目标及写入开关、独立回读、预期拒绝与传输异常的区别、CLF 证据判定、凭据脱敏和中断恢复。
- 本机真实生成客户端：读取 795 个可用服务，验证 `ProductMaint` 的公开签名、实际类型化请求及非法字段拒绝；这些检查不调用业务库。
- 真实客户端对本机临时 HTTP 端点执行 SOAP 登录，核对目标地址覆盖、官方客户端将 SOAP 故障包装为 `ExceptionLevel.Client` 的行为，以及密码脱敏；客户端故障不会按预期业务拒绝通过。
- 浏览器使用隔离存储与隔离业务回执，元数据表单来自真实客户端 DLL；验证单次与批量操作、双击去重、刷新恢复、环境共用、JSON / 表单保留输入及 1024 / 736 / 320 像素布局。
- 真实目标的登录、具体业务写入、部署来源一致性和完整 CLF 用例仍需要在页面配置目标后逐项执行，开发验证未向实际业务库写入测试数据。
- 最终全量回归：`python -m pytest tests -q`，578 项通过、57 项按环境条件跳过；浏览器验证无脚本错误，覆盖双击去重、提交时清除旧结果、刷新恢复和窄屏布局。
