# 只读查询复用

同一 Python 服务进程只维护一个串行执行的官方元数据只读进程。首次查询加载 MDB，之后不同查询复用该内存模型。结果缓存仍照常使用。

复用标识包含来源路径、MDB 内容 SHA256、SDK DLL、C# 桥和 PowerShell 启动脚本的 SHA256。标识变化或进程异常时销毁旧进程；距离上次使用超过 5 分钟时，下次请求重新创建。每次查询前后仍核对 MDB 内容哈希。

只允许 catalog/list/get/schema/impact/fields/inheritance/read_batch。创建预检会在内存中执行工厂和 setter，因此不进入共享进程；写入、编译和导出继续使用独立进程。超时会回收只读进程，下一次请求可以重新建立。服务正常关闭时也会回收。

每次未命中结果缓存的查询，artifacts 对应目录中的 bridge-timing.json 记录 worker_reused、mode、duration_ms，用于区分首次加载与跨调用复用。

本机副本测试：首次目录查询约 13.1 秒，后续新的对象查询约 0.39 秒，新的完整字段查询约 0.35 秒。耗时随机器、MDB 大小与负载变化，不等同于整轮模型问答耗时。
