# 问答延迟优化与回放（2026-10-25）

本次调整重点是减少模型等待与重复取数，不改变设计写入、预览确认、来源版本校验和 CLF 只读权限。

## 实现

- 首条消息立即使用本地规则生成标题。模型命名与图执行并行，慢标题不阻塞首段回答或流结束；结束/停止时回收命名任务。命名失败保留本地标题，不覆盖用户已经更改的标题。
- `get_designer_clf` 默认附带分析证据：直接调用的函数定义、函数参数、显式 `LabelId::` 标签、原有完整调用顺序/表达式/声明参数/官方引用。函数和标签去重，独立查询按每批最多 20 项读取。`include_analysis=false` 保持轻量读取；浏览器单纯浏览规则继续使用轻量接口。
- 聚合读取在最后核对初始 MDB 哈希；逐项失败与分页/引用截断信息保留。嵌套 CLF、callsuper 和动态调用未自动展开，回执和提示词明确标注边界。
- CLF 解释中，额外读取完整 CDO 时，模型只接收对象摘要和完整字段名称索引，字段属性标为未展开，并保留原始证据 ID。常规字段清单查询继续提供完整字段及类型，不使用八条样本代替全表。
- 完整 CLF 回执使用紧凑 JSON，保留调用顺序、禁用状态和全部参数，不进入通用深度/列表采样摘要。完整原始历史仍保留。
- 只读进程闲置保温由固定 300 秒改为 `DESIGNER_READ_WORKER_IDLE_SECONDS`，默认 900 秒，可设 60～3600 秒；MDB/SDK/桥实现版本改变时仍丢弃旧进程。
- 推理日志增加 `context_prepare_ms` 与 `model_request_ms`，区分上下文准备和模型请求阶段。

- 完整测试目录：634 通过，57 跳过。
