# Designer 程序优化记录（2026-10-11）

本轮依据 [程序复查](designer_program_review_2026-10-11.md) 修复已确认的问题，并更新 [能力说明](designer_capabilities.md)、[开发计划](development_plan.md) 和 README。

## 已完成的改动

| 问题 | 当前行为 |
|---|---|
| 停止聊天后保存继续，结果丢失 | 工具任务与聊天连接分开；完成或失败独立保存回执。刷新后恢复设计清单和工具结果，页面提示后台状态。相同调用标识的运行中任务与已保存结果不会重复执行 |
| 手动确认直接建立发布基线 | 点击核验后，在后台对照当前周期最终设计检查 SQL。全部通过且核验期间目标指纹不变，才建立发布基线和已发布 MDB 记录；失败保留原基线 |
| 自动发布只核对新增 CDO | 官方 Update DB 后对整个周期的编译元数据及物理列验收；通过后建立发布基线。更新执行了但验收失败时，审计仍记录数据库已经改变 |
| 聊天、MCP、页面使用不同的连续设计清单 | 共用项目周期入口，将 B0→B1、B1→B2 汇总为 B0→B2。相同周期复用已校验的差异产物，后续改动自动重新生成 |
| WCF 检查历史操作而非最终状态 | 计算最终字段名称和存在状态，再读取当前编译 MDB 的有效字段目录，包含继承字段。按实际字段验收程序集；缺少应保存字段时阻断 |
| 多次小批修改不累计 | 执行节点累计新增、修改和删除数，混合批次分别计数。后续调用按累计值触发已有确认规则 |
| 任意用户名可进入文件路径 | 会话与聊天 API 限定配置的工作台用户；用户名及会话文件名校验目录边界和 Windows 保留名称 |
| 历史聊天仍显示旧工作版本 | 已有设计的对话跟随所属项目最新清单，累计同一工作 MDB 当前周期的改动；旧版本的编译回执不能用于新版本 |
| 只读查询长期保留完整 MDB | 按 MDB、SDK、桥接实现和查询条件缓存结果；缓存最多 128 项、16 MiB。未命中时使用隔离副本，查询结束或失败后释放临时 MDB |
| 会话文件可能在中途退出时被截断 | JSON 写入临时文件后原子替换；遇到 Windows 临时文件锁时有限重试 |

## 保持的产品约定

- 同一项目持续编辑固定工作 MDB。厂商操作先在隔离副本执行，校验成功后提交到工作文件。
- 发布后下一轮首次实际修改前备份上一版 MDB，项目最多保留 10 份备份。正常设计阶段不会每次创建版本备份。
- 测试库默认不要求 SQL 备份；只有显式启用配置时才要求备份凭证。SQL 备份与 MDB 版本备份分别管理。
- 多人修改的合并与兼容由 Opcenter 处理；本程序检查版本并接收已确认的合并结果。
- 历史审计快照、发布基线、工作 MDB 和已有备份不参与本轮自动清理。旧的只读临时副本尚未批量删除。

## 验证

- 全量自动回归：**230 项通过，7 项环境相关测试跳过**。
- 单独启用真实安装的厂商组件：**3 项通过**，覆盖重命名与删除、CLF 调用删除与事件解绑，以及只读查询缓存和临时副本释放。全部使用私有副本，并核对原 MDB 哈希不变。
- 页面脚本语法检查：设计助手和进度页的 2 段脚本通过。
- 本地服务已重启；设计助手、设计记录、进度、日志页面均返回 200。现有对话历史和设计进度可读取，进度没有报错。
- 文档中 37 个本地链接检查通过，变更格式检查通过。
- 新增回归覆盖取消期间后台保存、断线后的结果恢复、同调用防重复、累计阈值、路径边界、连续设计周期统一、手动及自动发布验收失败、SQL 核验期间漂移、WCF 最终字段和继承、Windows 原子保存与缓存失效。

本轮验证未执行真实数据库发布、数据库恢复或服务器工作 MDB 覆盖。SQL 发布及故障分支采用隔离适配器测试；真实组件测试只修改本地私有副本。

## 仍需后续增强

1. CLF 声明参数的创建、删除、类型、方向和集合属性；Query 参数类型的专用管理。现有调用参数表达式和文本参数同步继续可用。
2. 引用影响图与重命名预览，尤其是表达式和查询文本中的引用。
3. 数据类型缩窄与转换检查，以及物理索引的存在、列顺序、唯一性和排序方向验收。
4. WCF、CLF 与 Query 的实际服务运行用例；REST、原生 XML Import 往返与自动服务部署按独立里程碑推进。
5. 历史审计快照的长期归档与清理策略，需要保留设计周期、发布基线和恢复所依赖的材料。

停止回答不会强杀厂商保存。正常关闭服务会等待后台任务；强制终止进程或系统断电后，仍需按实际文件与数据库重新核对。单用户会话归属限制也不等同于完整身份认证。
