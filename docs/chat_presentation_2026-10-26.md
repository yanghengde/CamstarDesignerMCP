# 聊天问答与回复样式

本次参照 [CamstarModelingMCP](https://github.com/yanghengde/CamstarModelingMCP/tree/960dd1a001dfb8795585ab4e5a4f781a5c79212c) 的聊天工作区实现，参考版本为 `960dd1a001dfb8795585ab4e5a4f781a5c79212c`，主要依据 `static/workspace.css`、`static/workspace.js` 和首页。

## 已实现

- 设计助手及 CLF 历史对话采用白底文档式回复、浅蓝提问气泡、居中正文与紧凑输入框。输入框随内容增长，窄屏保持可用。
- 统一标题、段落、列表、表格、代码块、链接和引用样式。宽表格与代码块在各自区域内滚动。
- 中间分析及工具调用放入默认折叠的执行记录，最终答复直接展示；历史长答复不再整体折叠。设计结果、字段目录及 Excel 确认卡继续使用既有交互。
- CLF 工作区内的按需助手复用相同 Markdown 与执行记录组件。Markdown 解析库不可用时保留安全文本或原有安全解析方式。
- HTML 仍由 DOMPurify 清理，不向执行记录添加工具参数或原始敏感回执。

## 状态与计时

后台任务状态优先于页面流结束，等待确认不会被误写成完成；“回复已结束”仅指回答结束。后台时间齐全时显示任务用时，否则实时回答显示本页观察用时。旧历史未保留页面计时，显示执行记录并说明，无估算耗时。

切换会话会清理页面计时器；后台继续执行、停止回答、空草稿、审批及保存接口沿用原实现。

## 验证

- 完整普通测试：671 通过、60 跳过。
- 新增回归覆盖任务状态、等待确认、过期状态、计时清理、安全文本回退及真实发送函数的流式中间分析折叠。
- 隔离页面使用合成历史与 SSE 检查桌面、352px 窄屏、输入框伸缩、多轮最终答复、表格、代码块及危险链接清理；未调用模型或业务工具。
- 本次没有变更 Designer SDK、工作 MDB 保存、编译、发布或业务测试逻辑。
