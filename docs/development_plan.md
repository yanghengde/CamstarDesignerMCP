# Designer MCP 开发计划

目标：自然语言完成 Designer 定义检索、设计变更、冲突与影响分析、测试导入、数据库更新和服务生成。浏览器与 MCP 使用同一工具注册表。

## 验收主线

`ExProduct` 继承 `Product`，增加 `ExDescription` 字段，String 最大长度 200。长度属于字段类型；持久化时再校验数据库列长度。不得修改共享的 `[String]` 类型来实现单个字段需求。

| 阶段 | 交付 | 验收条件 |
|---|---|---|
| 1 定义目录 | CDO、字段类型、CLF、事件、函数、Query、表、列、索引、映射、标签、工作区的查询；继承与引用追踪 | 在真实 MDB 副本查询，原文件哈希不变；未解析覆盖必须标注 |
| 2 设计编译 | 新建 CDO、字段和专用 String 类型；现有定义的属性更新、重命名；复杂定义使用真实导出模板 | 输出 XML、结构化计划、前置条件、影响报告和来源哈希；拒绝猜测未知 XML 属性 |
| 3 冲突与核对 | 源漂移、名称冲突、继承冲突、类型与列长度、预期值、设计包核对 | 重复名称与错误引用阻断生成；区分文件验证、目标验证及官方验证 |
| 4 测试导入 | 确认安装组件的官方导入入口；仅在独立测试副本导入；输出官方日志 | 官方重新读取并核对新增 CDO、父对象、字段类型与 200 字符限制；201 字符负例 |
| 5 发布 | Update DB、数据库差异、WCF/REST 服务生成与验证、回退材料 | 确认测试目标及备份；逐步保存实际执行结果；不能把程序退出码当作全部成功 |
| 6 完整覆盖 | CLF 顺序、参数、事件；Query 参数与 SQL；存储表列索引；映射；标签；工作区依赖 | 每类定义至少一个真实导出→变更→测试导入→重新导出的往返用例 |

## 实施约束

1. 所有读取、生成和核对能力优先实现；工具描述明确实际支持范围。
2. 从手册或安装组件确认 XML 属性名。真实 MDB 的列名不能直接当作 XML 属性名。
3. 新增专用 String 类型，避免改变已有类型的所有引用者。创建 CDO 自动产生 Object 字段类型，需核对厂商行为。
4. 客户工作区从真实目录选择；有多个候选时才询问。XML 不携带工作区选择时在包中明确记录。
5. 不直接修改生产 MDB。厂商自动导入/发布入口未验证时返回具体缺口，保留可审查的设计产物。
6. 全部状态由执行证据确定：draft、结构验证、目标前置条件验证、官方测试导入、发布、运行验证。

## 接续验收顺序

1. WCF：隔离生成、检查非零服务/数据契约数及程序集中的目标字段，读取现有连接配置；生成成功后备份部署目录，再验证服务可用性与回退。日志、驱动和进程位数不匹配时明确阻断部署。
2. REST：定位实际TypeGenerator/EDM和部署目录，核对官方输入及输出，运行现有接口回归后接入生成与发布。
3. 原生XML Import：定位真正的Designer导入组件，在测试副本做导出→导入→再导出的往返。当前对象模型保存与Update DB路径已可用，不能标注成XML Import成功。
4. 复杂设计：补充Query参数语义、CLF表达式运行、工作区覆盖和删改影响验收。每类记录实际覆盖，持续增加专用操作。

WCF当前验收项：ProductMaint隔离生成通过官方回执，329个数据契约、4个服务；ProductChanges类型已读取，产物已复制回本地。ExProduct尚未进入该服务的可达对象图，不能仅凭IsWSExposedStd设置宣称已生成它的服务契约。全量服务包和部署仍待验收。安装版本StateChanged事件会导致参数不匹配，适配器已移除订阅。

原生XML入口已定位：Designer2/Designer.Net.UI.exe实际启动InSite Administration/Designer/ImportMetaData.exe；InSiteImport.Import提供PromptToImportConsole2。inspect_designer_installation已接入MCP并从授权共享读取真实配置和版本。32位COM/Jet已在SQL Agent自己的副本中以读写方式打开。共享账号上传的文件对作业账号只有读取权限，因此适配器需先由工作进程复制到自己的子目录，不更改安装和共享目录的权限。创建包与简单字段类型Description更新包的控制台导入均返回false，Import.log记录ImportConflict及处理终止；继续定位共同的登录/导入前检查故障，不能宣称原生导入成功。

恢复流程同时维护MDB基线：备份保存能与目标指纹匹配的已发布MDB记录；恢复后再次核对指纹和MDB哈希。旧凭证没有对应MDB时标记基线待核对并阻断后续发布，避免数据库回退后仍使用最新MDB覆盖设计。
