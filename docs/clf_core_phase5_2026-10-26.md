# CLF 第五批：直接调用者及入口参数迁移

本批接续客户事件入口迁移，补充独立客户规则中的直接 CLF 调用迁移。操作仍进入同一份预检、审核、保存和回读流程，不新增业务执行通道，不操作用户管理的 8032 服务进程。

## 操作设计

在声明参数变更弹窗选择“先复制客户规则”，然后逐个读取直接调用者的库参数和入口参数。默认不选择迁移。目标参数按当前拟定声明展示名称、类型、方向、多重性及表达式；原名改为新名时显示原表达式，新增参数保持明确的空表达式，可按要求填写。

选择迁移一个调用，意味着同步核对该调用者的全部事件入口。每个入口提供独立拟定表达式和动态标记，保留同一参数在不同入口上的不同值。新增参数、改名、类型、方向和删除变更都通过明确的完整目标参数清单表达，不推定表达式符合业务语义。

仍沿用声明的既有引用检查：规则内部表达式还引用旧声明时，改名/删除会被阻止，本批不会自动重写 `CLF::` / `DBCLF::` 表达式。

方案差异展示原调用及 ID、原规则和目标规则、原参数和拟定参数；官方预检和保存后的核对结果分别呈现。替换调用后产生新调用身份，保留原顺序与启用状态；同名重复调用以真实调用 ID 区分，未选调用保持不变。原被调用规则保持不变。

## 合同与边界

新增 `migrate_clf_call`：owner、call_id、expected_clf、clf、expected_sequence、expected_active、expected_parameters、expected_bindings、target_declarations、parameters、bindings。

- 原库参数及所有入口的完整附着快照包含稳定身份、表达式和动态标记，入口快照还包括对象、字段、事件、功能配置及身份。
- 原调用、入口、原值、顺序或启用状态变化时拒绝；目标声明与用户核对的类型或属性不同也拒绝。
- 拟定库参数和每个入口的拟定参数必须恰好覆盖全部目标声明；空字符串与未提交明确区分。
- 本批每个调用最多 50 项声明、调用者最多 20 个入口/合计 5000 项附着值、100 个定义调用。同一调用者每份方案只迁移一个调用，避免多个旧快照互相覆盖。限制由前后端共同执行。
- 只迁移当前工作区的独立客户调用者及当前客户入口；系统、继承覆盖及递归调用不自动迁移。迁移目标需为同类、不同的独立客户 CLF。
- 官方重新附着后按真实身份写入明确的拟定值；保存前和保存回读后都核对调用者全部库调用、全部入口和目标声明。其他操作若改变已核对范围，不能视为预检通过。

新增只读接口 `GET /api/clf/workspace/caller-migration/{project}`，需用户、源哈希、原规则、调用者和调用 ID。它只在用户明确读取时获取完整合同，普通助手和目录不加载所有调用者入口。

前端采用 `clf-call-migration.js` 组件，由原 `/clf-core.js` 路径顺序提供，避免新增脚本路由与旧后端混用。后端能力标识为 `explicit_direct_call_and_all_entries_v1`；旧进程中不允许准备调用迁移，需由用户自行重新加载后端。

## 后续工作

系统及继承入口的显式客户覆盖、动态引用迁移、递归调用迁移、运行值联动和真实业务验收仍需后续完成。表达式配置和元数据预检不证明运行时语义正确，编译或保存也不代表数据库/WCF 已部署。

## 验证记录

- 普通完整回归：703 项通过、64 项按环境条件跳过。迁移、核心接口和交付链相关回归：53 项通过、4 项跳过；JavaScript 语法及差异空白检查通过。
- 两项真实安装 SDK 专项分别通过。正向场景包括同一规则的两个同名调用、两个入口、不同库/入口表达式、原调用禁用状态，以及目标参数改名、String → Integer、In → In/Out 和新增 Boolean 参数。只迁移选中调用，另一调用及其各入口原值保持一致。
- 删除最后一个声明参数的独立副本保存及回读通过。SDK 构造调用时可能带入待删除声明的临时参数，现仅移除新调用中未保存且不在已审核有效目标声明中的值；保留声明删除标记，由官方 SaveAll 处理声明生命周期。
- 原值快照与目标清单缺项、入口原值漂移、目标类型不一致、启用状态不一致、迁移后额外修改及同一调用者重复迁移均被阻止；每轮预检前后私有工作 MDB 哈希一致。
- 读取、构造和关联均使用官方身份；新建 CLF 的默认函数名可能仍为内部生成名，不从规则显示名拼出函数身份。
- 官方差异 XML 导出完成，通过项目现有结构检查；未执行 XSD/Designer XML 导入或真实业务交易验收。
- 正向迁移结果和删除最后一个声明参数的结果均完成 MetadataCompile，编译前后私有工作源哈希一致；这只验证这些隔离元数据结果能够编译。
- 界面组件的 DOM 回归覆盖默认不迁移、全部入口值分别保留、动态标记、手工表达式随改名保留、过期上下文和重复调用者拒绝。浏览器拒绝离线 file 协议预览，因此本轮没有完成新增组件的浏览器视觉验收，也没有以启动临时服务绕过该限制。
- 用户原工作 MDB 保持不变，写入均发生在独立测试副本；证据保存在 `tmp/clf-caller-migration-research/acceptance`。全程未启动、停止、重启或接管用户的 8032 服务。
