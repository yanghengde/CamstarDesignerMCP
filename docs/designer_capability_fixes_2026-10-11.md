# Designer 能力修复 · 2026-10-11

本次根据能力 Review 修复实现，并补充专用操作。工作 MDB 保持固定路径，发布后的首轮修改自动备份，最新备份最多保留 10 条。多人修改和文件合并由 Opcenter 处理。

## 已修复的问题

- 文件交接前检查 Designer 已保存的版本；检测到外部改动后停止覆盖。本地生成期间和提交前也检查服务器版本。
- “同步文件”实际接收已保存的服务器 MDB，验证、导出差异并生成新的设计清单，继续使用同一个工作文件。本地有尚未交接的修改时，旧服务器版本不能覆盖本地。
- 两边同时修改时保留文件。用户在 Opcenter 合并并明确确认接收后，工具只接收指定 SHA256 的合并版本。
- 重命名后的保存回读使用稳定定义 ID；同一批次还能通过旧名称定位刚重命名的对象。
- 删除 XML 可通过结构检查；保存回读核对定义已删除。更新回读检查具体属性，不能仅凭定义存在宣称成功。
- 进度页支持更新、删除、同步和恢复，列出动作、所属对象、名称与定义类型。WCF 对象列表排除本次删除的对象。
- 连续设计的数据库验收使用最终 MDB 与本轮最早基线的差异，避免逐个检查已被后续操作更改的中间版本。
- SQL 验收覆盖变更的对象、字段类型、CLF/调用/参数、事件绑定、查询/文本/参数、映射、列、索引、标签元数据，并检查具体值及删除结果。旧发布基线继续使用原有指纹算法；新发布记录采用扩展后的算法。
- 安全计数解析通用设计工具中的实际新增、更新和删除动作，保留现有确认阈值。

## 新增专用能力

| 场景 | 操作 | 范围 |
|---|---|---|
| 继承了错误对象 | `change_parent` | 客户拥有、没有下层覆盖、用途类别一致的 CDO；检查原父对象、继承环和字段冲突。 |
| 存储分类选择错误 | `change_storage_category` | 更换已有元数据存储分类；不迁移工作区，也不搬移磁盘目录。 |
| 撤销继承字段的修改 | `remove_field_override` | 撤销当前客户覆盖，恢复父级或下层定义；不能用于删除父对象字段。 |
| 事件绑定错误或取消绑定 | `replace_event_binding` / `unbind_event` | 检查原 CLF；替换采用新 CLF 默认参数。 |
| CLF 函数调用错误或多余 | `replace_clf_function` / `remove_clf_function` | 使用真实调用 ID 与原函数名；替换采用新函数默认参数，删除后调整剩余顺序。 |
| 字段映射错误或多余 | `update_field_map` / `remove_field_map` | 保留所属映射的源、目标 CDO，检查原字段；同名定义可用 `id:CDOFieldMapID` 定位。 |
| 修改查询文本后参数不匹配 | `sync_query_parameters` | 文本 `patch` 同时调用厂商参数同步；参数名称和顺序遵循安装版本的厂商规则。 |
| 查询字段引用 | 字段级 `analyze_designer_where_used` | 返回字段映射、直接事件、继承覆盖及厂商使用判断；表达式和运行时引用仍需 Designer 检查，返回 `complete=false`。 |
| Designer 修改后继续聊天设计 | `sync_designer_working_file` | 接收已保存的 MDB，保留固定工作路径和设计清单。 |
| 恢复历史 MDB | `restore_designer_mdb_backup` / 备份区“恢复此版本” | 恢复前保留当前 MDB。只恢复 MDB，数据库与 SiteInfo 保持当前版本；恢复后重新核对、编译和发布。 |

## 验证与边界

自动测试覆盖文件漂移保护、固定路径、备份恢复及数量限制、会话归属、进度、操作计数和元数据验收。浏览器验证了恢复确认、实际文件内容、恢复前版本下载和备份列表轮询。

最终结果：195 项自动测试通过，6 项需要专门环境的测试默认跳过；其中新增的 2 项真实厂商组件回归测试已另行启用并通过。浏览器测试通过。本地服务已重启，设计助手、设计记录和设计进度均返回正常页面，已有设计任务没有读取错误。

真实厂商组件实验均使用独立本地 MDB 副本，验证保存、重新加载和官方编译。已发布 ExStatus 的编译差异与 SQL 目标做了只读核对，现有发布基线指纹保持一致。验证过程中未发布数据库，也未改动用户的项目或服务器工作 MDB。

原生 XML Import 往返、跨用途类别继承迁移、工作区迁移、已有索引列集合调整、CLF 自身参数的完整生命周期、WCF 部署与运行行为、REST 验收仍需要专门适配或在 Designer 中处理。元数据验收不等于服务运行验收。
